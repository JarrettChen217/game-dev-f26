# README 中文精翻设计

## 目标

在仓库根目录新增 `README_zh.md`，为英文 `README.md` 提供准确、自然、便于课程学习的中文译本，同时帮助读者熟悉课程使用的英文技术术语。

## 翻译策略

- 使用自然流畅的中文表达，不采用机械逐词翻译。
- `agent`、`provider`、`fixture`、`structured output`、`Setup Verification` 等重要英文术语在首次出现时保留英文并附中文解释；后续按语境使用英文术语或简洁中文。
- 课程名、游戏名、产品名、框架名、模型服务名称和专有名词保持原文。
- 命令、代码块、环境变量、文件路径、模型 ID 和配置值保持原样。
- 不添加原文没有的课程要求、结论或操作步骤。

## 文档结构

- 保留原 README 的标题层级、段落顺序、列表、表格、引用和代码块。
- 保留原有链接目标；仓库内相对链接继续指向相同文件。
- 在文档开头注明这是中文翻译，并提供返回英文原文的链接。
- 文件名固定为仓库根目录下的 `README_zh.md`；不修改 `README.md`。

## 校对与验收

- 对照英文原文逐节检查，确保标题、段落、列表、表格行和代码块无遗漏。
- 检查 Markdown 围栏、链接目标和表格列数是否完整。
- 搜索容易误译的要求性词语，如 `must`、`required`、`optional`、`only`、`never`，确保义务强度保持一致。
- 检查关键术语首次出现时是否包含中文解释。
- 最终检查 Git diff，确认只新增约定的中文译本及本设计说明。
